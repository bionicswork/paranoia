# PARANOIA · Prompt Forge

Generador de prompts de mini-demos para el universo de Paranoia, con estética greenpunk, conceptos del libro, filtros por mecánicas y salida lista para copiar en IA.

## ¿Qué hace?
- Selección de conceptos del universo Paranoia
- Parámetros de juego: público, plataforma, dificultad, duración
- Selección de mecánicas y estética visual
- Generación automática de prompt para IA
- Copiar al portapapeles
- Descargar como archivo Markdown

## Cómo usarlo
1. Abre el archivo `index.html` en tu navegador.
2. Selecciona los conceptos.
3. Ajusta los parámetros del mini-demo.
4. Pulsa “Generar Prompt”.
5. Copia o descarga el resultado.

## GitHub Pages
Este proyecto es estático y funciona muy bien en GitHub Pages.

Pasos:
1. Subir `index.html` al repositorio
2. Añadir `README.md`
3. Añadir `.nojekyll` (vacío)
4. Ir a Settings → Pages
5. Seleccionar:
   - Deploy from a branch
   - Branch: main
   - Folder: / (root)
